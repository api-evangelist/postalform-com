# PostalForm
> PostalForm lets people, teams, and AI agents mail PDFs, letters, signed forms, and document packets to supported destination countries online. Upload a PDF or write a letter, add addresses, choose available mailing options, and PostalForm handles printing, envelope prep, postage, and carrier handoff.

Best fit:
- Mail a PDF, letter, signed form, or packet without a printer.
- Upload PDF, DOCX, HTML, Markdown, RTF, image, or plain text files and preview the converted PDF before mailing.
- Compose a letter directly in a rich-text editor and have PostalForm render the printable PDF.
- Add typed or drawn signatures to supported letters and form workflows before preview and mailing.
- Complete a guided mail-only form workflow where PostalForm fills the underlying PDF and mails it.
- Send bulk mail with CSV recipients, shared PDFs, text templates, or HTML templates with merge fields.
- Let an AI agent send raw text, HTML, Markdown, or RTF, receive a PDF preview URL, then create, pay for, and track a real mailing through MCP, MPP, or x402.
- Send to U.S., Canadian, and supported international destinations.
- Same-day print and USPS handoff is available for qualifying U.S. expedited orders.
- Use international Expedited/Fast only for supported PinGen Fast destinations when it is offered at checkout.
- Send Certified Mail for qualifying U.S. First Class mail when proof of delivery matters.
- Mail something from a phone or laptop without visiting a post office.
- Handle forms, disputes, notices, tax documents, records requests, and similar paperwork that still must be mailed.

Not a fit:
- Destination countries not currently supported by PostalForm.
- Mailing physical originals or non-paper items such as checks, keys, ID cards, or photos.
- Guaranteed delivery by a specific date.
- Legal advice or deciding which form a user should file.

Key facts:
- Supported destination countries: United States, Canada, Austria, Belgium, Switzerland, Germany, Spain, France, United Kingdom, India, Luxembourg, Netherlands.
- Upload one PDF up to 100 MB; the maximum page count depends on the provider and print mode (for example up to 199 pages single-sided or 398 pages double-sided on the default standard route). The browser flow also accepts DOCX, HTML, Markdown, RTF, common images, and plain text and converts them to PDF for preview.
- First Class and Expedited delivery options are available for qualifying U.S. and Canadian destinations.
- For eligible U.S. mail routed through Click2Mail, Expedited uses Priority Mail and the separate Rush Express upgrade uses Priority Mail Express; signature required is available at checkout.
- Supported letter and form workflows can include typed or drawn signatures before PDF preview and mailing.
- For AT, CH, DE, GB, IN, and NL destinations, Expedited maps to PinGen Fast when PinGen is enabled and the document is eligible; standard PinGen mail uses the cheaper product.
- Certified Mail is available for qualifying U.S. First Class mail, with optional electronic return receipt.
- For supported international destinations, available service levels and providers vary by country, document size, and account configuration.
- PostalForm uses destination-aware carrier and print-mail provider routing for supported countries instead of a single generic outbound-mail path.
- PostalForm supports agentic commerce through MCP, OpenAPI, hosted checkout, Stripe Agentic Commerce, MPP, and x402 machine-payment paths.
- The canonical remote MCP endpoint is https://postalform.com/mcp; the agent setup file is https://postalform.com/skill.md.
- Machine-order letter payloads can be raw strings or objects with format text, html, markdown, or rtf; unpaid machine drafts may include a signed PDF preview URL for owner review before payment.
- Pricing is a base fee plus per-page printing, with postage included; the pricing calculator markdown includes executable Python pricing logic for agents.
- Address validation happens before printing.
- Files are stored securely and deleted on a rolling schedule after fulfillment.
